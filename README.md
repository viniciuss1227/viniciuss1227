## 🚀 Projetos em Destaque (Provas Técnicas)

### 🧠 [SRS Flashcards – Sistema de Repetição Espaçada](https://github.com/viniciuss1227/srs-project)
* **Stack:** Python, FastAPI, SQLAlchemy, SQLite, JavaScript (Vanilla), HTML5, CSS3
* **O que faz:** API fullstack desenvolvida a partir de uma **motivação pessoal**: aplicar o método SRS (*Spaced Repetition System*), a mesma metodologia que utilizei em minha jornada de autonomia e fluência no idioma inglês. 
* **Diferenciais Técnicos:** Implementa um algoritmo customizado de agendamento temporal (*Again, Hard, Good, Easy*) para cálculo dinâmico de intervalos de revisão por card, com persistência estruturada via SQLAlchemy e interface SPA consumida de forma assíncrona.

### 🤖 [Resumidor de Texto com IA](https://github.com/viniciuss1227/resumidor-texto-ia-php)
* **Stack:** PHP, MySQL, cURL, APYHub API, HTML5, CSS3
* **O que faz:** Aplicação web backend estruturada para o consumo e processamento assíncrono de serviços externos de Inteligência Artificial via requisições HTTP (`cURL`) para sumarização automática de textos.
* **Diferenciais Técnicos:** Implementação focada em segurança da informação, utilizando *Prepared Statements* em banco de dados MySQL para garantir a integridade e mitigar vulnerabilidades de SQL Injection.
